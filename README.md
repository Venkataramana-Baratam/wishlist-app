# Wishlist App

A simple browser-based wishlist (or to-do) application built with HTML, CSS, and JavaScript.  
Users can add items to a wishlist, mark them as completed, and delete them.  
All data is stored locally in the browser using `localStorage`, so the list persists across page reloads.

---

## Features

- Add new wishlist items
- Mark items as completed (checkbox)
- Delete items from the list
- Automatically saves and restores items from browser `localStorage`
- Generates unique IDs for each item
